# CodeAlpha CGPA Calculator
A C++ console-based CGPA Calculator developed as part of the CodeAlpha C++ Internship.
 ##  Project Overview
This program allows students to enter information about their semesters, courses, grades, and
credit hours. It calculates the GPA for each semester and the overall CGPA. 
##  Features
- Enter multiple semesters
- Enter multiple courses for each semester
- Enter course names
- Enter grades and credit hours
- Validate entered grades
- Validate credit hours
- Calculate grade points for each course
- Calculate semester GPA
- Calculate overall CGPA
- Display a summary of courses, grades, credits, and points

## Calculation
The program calculates the grade points for each course using:
**Course Grade Points = Grade Point × Credit Hours**
Semester GPA:
**GPA = Total Grade Points ÷ Total Credit Hours**
Overall CGPA:
**CGPA = Total Grade Points from all semesters ÷ Total Credit Hours from all semesters**
## How to Run
1. Download or clone this repository. 2. Open `CGPA.CPP` in a C++ compiler or IDE. 3. Compile the program. 4. Run the program. 5. Enter the number of semesters, courses, grades, and credit hours when prompted.
